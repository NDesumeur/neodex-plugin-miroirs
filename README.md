# Miroirs

Un casse-tête en pixel art : tourne les miroirs pour guider le laser jusqu’à tous les cristaux.

*English version: [README.en.md](README.en.md)*

## Niveau du jour (nouveau en 1.2.0)

Un niveau avec prisme et cristaux de couleur, tiré d’après la date : le même pour tout le monde chaque jour, avec une série de jours (et son record). Les indices marchent aussi dessus ; après l’avoir fini, on revient à son niveau.

## Commandes

- **Souris** : clique sur un miroir pour le tourner.
- **Clavier** : les **flèches** déplacent le viseur, **Entrée** ou **Espace** tourne le miroir. **H** : indice · **R** : recommencer.
- **Manette** : la croix ou le stick déplace le viseur, **A** tourne, **Y** donne un indice, **LB** recommence.

## Comment ça marche

- Chaque miroir renvoie le laser à angle droit. Les **murs** l’arrêtent, les **cristaux** le laissent passer.
- Allume **tous les cristaux** en même temps pour finir le niveau.
- **Trois étoiles** en peu de coups. Un **indice** remet un miroir dans le bon sens, mais le niveau ne vaut plus qu’une étoile.
- 80 niveaux, de plus en plus grands, avec des miroirs pièges hors du chemin.
- Le laser brille (un halo, un cœur blanc) et lance des **étincelles** sur chaque miroir qu'il touche.
- **Plein écran** : le bouton du même nom ; Échap pour en sortir. Hors plein écran, le jeu prend toute la place que laisse la fenêtre.

## Les niveaux avancés

À partir du niveau 41, de nouveaux éléments arrivent :

- les **filtres de couleur** (rouge, vert, bleu) : le laser qui les traverse prend leur couleur ;
- les **cristaux de couleur** : ils ne s'allument qu'avec un laser de leur couleur ; le cristal blanc, lui, s'allume avec toutes ;
- le **prisme** (à partir du niveau 45) : il sépare le laser en deux rayons, à gauche et à droite ; il faut alors guider les deux.

## Données et synchronisation

Niveaux et étoiles sont enregistrés par NeoDex, sauvegardés et synchronisés entre tes PC si la synchro est activée.

## Installer

Dans NeoDex : **NeoStore → À découvrir → Miroirs → Installer**.
